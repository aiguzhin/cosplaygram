# Cosplaygram

Платформа для косплееров Казахстана и Центральной Азии в духе Instagram.

## Что умеет

- **Лента** с фото костюмов, лайками (в том числе двойным тапом) и комментариями
- **Истории на 24 часа** с полноэкранным просмотром
- **«Как это сделано»**: пошаговые посты процесса с подписью к каждому фото
- **Профили** косплееров: фото, специальность, город, био, сетка публикаций
- **Поиск** по материалам, мастерам, персонажам и городам
- **Форум** с разделами: материалы, пошив, реквизит, парики, фото
- **Календарь** конкурсов, фестивалей и встреч с фильтром по городу
- **Чат** с комнатами по городам
- **Конкурс месяца**: топ костюмов по лайкам
- Светлая и тёмная тема, адаптив под телефон

## Запуск локально

```bash
npm install
npm start
# http://localhost:3000
```

## Деплой на Render

В репозитории есть `render.yaml`. На Render: **New → Blueprint** (или Web Service) → выбрать этот репозиторий.
Build: `npm install`, Start: `npm start`.

> На бесплатном тарифе Render диск временный: после перезапуска сервиса данные возвращаются к демо-набору.
> Следующий шаг — подключить базу (например, Supabase) для постоянного хранения.

## Стек

Node.js + Express, данные в JSON-файле (`data/db.json`), фронтенд на чистом JS без сборки.

## Структура

```
server.js        API и раздача статики
seed.js          демо-данные (помечены как «Демо»)
public/          интерфейс: index.html, styles.css, app.js
render.yaml      конфигурация Render
```
