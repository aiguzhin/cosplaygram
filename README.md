# Cosplaygram

Международная платформа для косплееров в духе Instagram: страны, города, чаты по странам.

## Что умеет

- **Выбор персонажа**: 127 героев аниме, манги, книг, фильмов, комиксов и игр (по рейтингу популярности у косплееров) — сайт перекрашивается в их стиль; на карточках фото косплея участников или свободные фото с Wikimedia Commons (`#/credits` — авторы)
- **Личные сообщения**, редактирование публикаций, «Пойду» и «В календарь» у мероприятий, фильтры по аниме/манге/дорамам/фильмам/играм
- **Приложение на телефон**: сайт устанавливается на экран «Домой» (PWA)

- **Лента** с фото костюмов, лайками (в том числе двойным тапом) и комментариями
- **Истории на 24 часа** с полноэкранным просмотром
- **«Как это сделано»**: пошаговые посты процесса с подписью к каждому фото
- **Профили** косплееров: фото, специальность, город, био, сетка публикаций
- **Поиск** по материалам, мастерам, персонажам, городам и странам
- **Мероприятия**: фестивали, соревнования, ивенты, вечеринки, сходки, мастер-классы; отметка «★ Крупный фестиваль»; итоги прошедших — победители по номинациям со ссылкой на профиль или Instagram
- **Профиль**: «Ваше лучшее качество», ссылки на Instagram, TikTok, Telegram, VK, YouTube, «Достижения» (призы, жюри, гость, организатор); победы из итогов попадают в профиль сами с пометкой «Подтверждено»
- **Заказы у мастеров**: «Принимаю заказы», услуги с ценами и сроками, заявка мастеру, статусы (новая → в работе → выполнен), отзывы с оценкой, рейтинг в профиле, фильтр «Принимают заказы»
- **Открыто для гостей**: профили, работы, мероприятия с итогами и форум видны без регистрации; ссылки `/u/ник`, `/p/работа`, `/e/мероприятие` показывают превью в Instagram и Telegram; `sitemap.xml` для поисковиков
- **Админ-панель** (`#/admin`): участники, галочки подтверждения, роли (участник / модератор / разработчик), удаление аккаунтов, жалобы, фото персонажей. Разработчики задаются в `DEVS` в server.js (aiguzhin) и переменной `DEV_USERNAMES`
- **Языки**: 115 языков интерфейса (автоперевод Google), язык браузера выбирается сам, арабский и иврит — справа налево
- **Весь мир**: страна у профиля, мероприятий и тем форума, фильтры по стране и городу, чат каждой страны, лента «Моя страна»
- **Форум** с разделами: материалы, пошив, реквизит, парики, фото
- **Мероприятия**: фестивали, косплей-шоу, встречи и мастер-классы с фильтром по городу
- **Чат** с комнатами по городам
- **Костюм месяца**: топ костюмов по отметкам «нравится»
- Светлая и тёмная тема, адаптив под телефон

## Запуск локально

```bash
npm install
npm start
# http://localhost:3000
```

Ещё: регистрация и вход, подписки и лента подписок, уведомления, закладки, жалобы и панель модерации,
настройки профиля с выбором цвета, смена пароля.

## Доступ

Сайт закрыт для гостей: сначала регистрация или вход, потом лента. Демо-фото в `public/demo` сгенерированы
для примера (оригинальные образы) и удаляются вместе с демо-профилями в панели модерации.

## База данных

- С переменной `DATABASE_URL` приложение работает с PostgreSQL (Render Postgres, Supabase, Neon — любой).
- Без неё — встроенный PostgreSQL (PGlite) в папке `data/`, удобно для локальной разработки.
- Таблицы создаются автоматически при запуске; в пустую базу загружаются демо-данные (помечены «Демо»).
- Первый зарегистрированный участник становится модератором. Ещё модераторов можно задать
  переменной `ADMIN_USERNAMES=nick1,nick2`.

## Деплой на Render

`render.yaml` описывает веб-сервис и базу PostgreSQL. Render сам передаёт адрес базы в `DATABASE_URL`.

## Стек

Node.js + Express + PostgreSQL, фронтенд на чистом JS без сборки, фото хранятся в базе.

## Структура

```
server.js        API и раздача статики
db.js            подключение к PostgreSQL и схема таблиц
seed.js          демо-данные (помечены как «Демо»)
public/          интерфейс: index.html, styles.css, app.js
render.yaml      конфигурация Render
public/themes.js каталог персонажей и их темы
public/countries.js список стран (общий для сервера и сайта)
public/chars/    фото персонажей (Wikimedia Commons) и credits.json
scripts/         подбор фото персонажей (запускается в GitHub Actions)
```

## Переезд базы и фото

- `NEW_DATABASE_URL` — строка подключения новой базы (Neon). Если новая база пустая, а `DATABASE_URL` (старая база Render) ещё жива, при запуске все данные переносятся автоматически, включая входы.
- `CLOUDINARY_URL` — хранилище фото (`cloudinary://ключ:секрет@облако`). Новые фото сразу уходят туда, старые переносятся в фоне, ссылки `/img/…` продолжают работать. Вместо Cloudinary можно `SUPABASE_URL` + `SUPABASE_SERVICE_KEY`.
- Резервная копия: «Админ-панель → Скачать копию» (только для разработчика).
- `.github/workflows/keepalive.yml` раз в час проверяет, что https://cosplaygram.kz отвечает (если нет — GitHub пришлёт письмо). Старый адрес cosplaygram.onrender.com пересылает все ссылки на cosplaygram.kz. Чтобы бесплатный Render не засыпал (иначе по старой ссылке видно экран «Загрузка приложения»), сервер в Казахстане каждые 5 минут заглядывает на него из `deploy/update.sh`.

## Свой сервер в Казахстане (для домена .kz)

Сайты в зоне .kz должны работать на серверах в Казахстане, а персональные данные граждан РК по закону хранятся в РК. Поэтому для .kz сайт ставится на VPS казахстанского хостинга (Ubuntu 22.04/24.04, от 1–2 ГБ памяти) одной командой:

```bash
curl -sL cosplaygram.kz/i | sudo bash
```

Скрипт ставит Docker, запускает сайт + Postgres + Caddy (https сам) и показывает код переезда: его вводят в «Админ-панель → Переезд на новый сервер» на старом сайте, и все данные переносятся; включает автообновление с GitHub каждые 5 минут и ночные копии базы в `/opt/backups`. В DNS домена: A-записи `@` и `www` → IP сервера.

## Вход через Google и Telegram

Кнопки «Продолжить с Google» и «Войти через Telegram» появляются в окнах входа и регистрации, как только разработчик вставит ключи в «Админ-панель → Вход через Google и Telegram» (или задаст переменные `GOOGLE_CLIENT_ID`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_NAME`).

- **Google**: Google Cloud → APIs & Services → Credentials → OAuth client ID (Web application), в «Authorized JavaScript origins» — `https://cosplaygram.kz`. Нужен только Client ID, секрет не нужен: сервер проверяет вход через Google.
- **Telegram**: @BotFather → `/newbot` → токен в админ-панель (сервер сам узнает имя бота), затем `/setdomain` → `cosplaygram.kz`.
- Первый вход создаёт профиль: человек выбирает ник, страну и город, пароль не нужен (задать его можно потом в настройках). В настройках можно привязать или отвязать Google и Telegram к уже существующему профилю.
- Instagram для входа на сторонних сайтах больше не годится: Meta закрыла Instagram Basic Display API 4 декабря 2024 года.

## Свои персонажи

Если у косплеера есть образ, которого нет в каталоге, он делает свою тему: «Настройки → Свой персонаж» или вкладка «Свои» в выборе стиля. Загружает фото своего косплея — сайт сам берёт из фото цвета (главный, второй, тёмный или светлый фон), можно выбрать шрифт и узор. Тема сразу включается, фото становится обложкой профиля. Галочка «Предложить в общий каталог» отправляет персонажа модераторам («Админ-панель → Персонажи от участников»); после одобрения он появляется у всех в выборе стиля с подписью «Косплей: @ник». До 12 своих персонажей на участника.
